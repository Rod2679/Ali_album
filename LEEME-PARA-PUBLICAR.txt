PARA PUBLICAR EN GITHUB PAGES

Este paquete ya está compilado. No necesitas instalar programas ni ejecutar
comandos.

1. Descomprime el archivo ZIP.
2. Abre GitHub Desktop y selecciona el repositorio:
   alii-eternal-sunshine
3. Copia TODO el contenido de esta carpeta a la carpeta local del repositorio.
   index.html debe quedar directamente en la raíz, no dentro de otra carpeta.
4. En GitHub Desktop escribe un resumen, por ejemplo:
   nueva experiencia musical para Ali
5. Presiona "Commit to main" y después "Push origin".
6. En GitHub abre:
   Settings > Pages
7. En "Build and deployment" selecciona:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
8. Presiona Save y espera uno o dos minutos.

La dirección normalmente será:
https://TU-USUARIO.github.io/alii-eternal-sunshine/

MÚSICA

La página necesita conexión a internet porque usa el reproductor oficial de
Spotify. Los navegadores no permiten iniciar sonido sin permiso: Ali debe tocar
"entrar y escuchar" una vez. Después, al cambiar de álbum o elegir una canción,
la página intentará reproducirla automáticamente.

Las canciones de petal que todavía no se han publicado aparecen marcadas como
"próximamente". La canción que ya tiene vista previa sí puede reproducirse.
